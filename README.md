# Backend Learning Platform

این پروژه یک وب‌سایت آموزشی در حوزه برنامه‌نویسی است که بخش Backend آن با Node.js توسعه داده شده.

ایده کلی پروژه شبیه پلتفرم‌هایی مثل سبزلرن و کدیاد است؛ کاربران می‌توانند در آینده دوره‌های آموزشی، مطالب و محتوای مرتبط با برنامه‌نویسی را مشاهده و از امکانات مختلف سایت استفاده کنند.

در حال حاضر تمرکز اصلی پروژه روی توسعه Backend و پیاده‌سازی منطق سمت سرور است و بخش Frontend هنوز برای پروژه در نظر گرفته نشده. پروژه همچنان در حال توسعه است و امکانات مختلف آن به مرور اضافه و کامل می‌شوند.

## بخش‌های اصلی پروژه

* طراحی APIهای مورد نیاز سایت
* مدیریت کاربران و اطلاعات آن‌ها
* احراز هویت و دسترسی کاربران
* مدیریت دوره‌ها و محتوای آموزشی
* مدیریت دسته‌بندی‌ها
* ارتباط با دیتابیس
* ساختاردهی پروژه به صورت ماژولار
* مدیریت خطاها و درخواست‌های HTTP
* توسعه و تست APIها

## تکنولوژی‌های استفاده شده

* Node.js
* Express.js
* MongoDB
* Mongoose
* JavaScript
* REST API

هدف اصلی من از ساخت این پروژه، کار کردن روی یک پروژه نسبتاً واقعی و نزدیک به نیازهای یک پلتفرم آموزشی است تا در کنار یادگیری Node.js، تجربه بیشتری در طراحی ساختار Backend، دیتابیس و APIها به دست بیاورم.

> این پروژه هنوز کامل نشده و به صورت مداوم در حال توسعه و اضافه شدن قابلیت‌های جدید است.
# Backend Learning Platform

This project is the backend of an online programming education platform, built with Node.js and Express.js.

The main idea is similar to platforms such as Sabzlearn and Codiyad, where users can eventually access programming courses, educational content, and other learning-related features.

At the moment, the main focus of the project is on building and improving the backend. There is currently no frontend for the project, as I’m focusing on the server-side architecture, APIs, database, and application logic.

The project is still under development, and new features and improvements are being added over time.

## Main Features

* Building and managing REST APIs
* User management
* Authentication and authorization
* Course management
* Educational content management
* Category management
* Database integration
* Modular backend structure
* Error handling
* API development and testing

## Technologies

* Node.js
* Express.js
* MongoDB
* Mongoose
* JavaScript
* REST API

The main goal of this project is to work on a real-world backend application and gain more practical experience with Node.js, API design, database management, and backend architecture.

> This project is still under active development and more features will be added in the future.
